# I-5 / Mercer St. On-Ramp Merge Analysis

This project looks into whether the lengthening of the Mercer Street on-ramp merging onto northbound I-5 would reduce congestion and delays during the weekday PM peak. The Mercer interchange sits between downtown, South Lake Union and Capitol Hill which may provide a lot of traffic that disrupts the flow of mainline northbound I-5. By using WSDOT volume and speed data from a typical weekday PM peak, I will build and calibrate microsimulation with Vissim of the ramp and a stretch of I-5 before and after the merge. The ramp geometry will be measured in QGIS. I will test a longer merge lane and compare data relating to delay, travel time and queue length against the existing layout. This project is an independent conceptual analysis that doesn’t account for right of way, cost and construction constraints.
