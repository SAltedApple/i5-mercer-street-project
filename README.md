# I-5 / Mercer St. On-Ramp Merge Analysis

This project looks into whether the lengthening of the Mercer Street on-ramp merging onto northbound I-5 would reduce congestion and delay during the weekday PM peak. The Mercer interchange sits between downtown Seattle, South Lake Union and Capitol Hill which may provide traffic that disrupts the flow of mainline northbound I-5. By using WSDOT volume and speed data from a typical weekday PM peak, I will build and calibrate a microsimulation with Vissim of the ramp and a stretch of I-5 before and after the merge. Because of the limits of the Vissim student license, the model will simulate only a 10 minute window of the peak. Ramp geometry will be measured in QGIS. I will test a longer merge lane and compare the data relating to delay, travel time and queue length against the existing I-5 layout. This project is an independent conceptual analysis and doesn't account in for right of way, cost nor construction constraints.
